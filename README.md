# CoreIris

A simple CoreIris Framework for data visualization.

CoreIris is aimed at developers who need a straightforward, dependable solution.

## Technology Stack

- python
- Modular architecture
- CI-ready (GitHub Actions)

## Installation

1. Clone the repository: `git clone https://github.com/minhokingkim/CoreIris.git`
2. `cd CoreIris`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
